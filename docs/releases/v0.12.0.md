## What's new

- **Screenshots and files reach sessions on your other machines.** Drop a file or an image on a tab on a host, or paste a screenshot or a copied file with `⌘V`, and Temple copies it to that host first, then types the host's path into your prompt, so the agent there can open it. Each copy goes into a new folder of its own in the host's temporary folder (`$TMPDIR` or `/tmp`) that only your account can read, never into your project. While it goes, "Copying shot.png to <host>, then adding its path to your prompt…" shows over the terminal's top-right corner. If a copy fails, nothing is typed and a note names the file, why, and what to do, until you click **OK**. Folders, and files over 100 MB, are not copied.
- **`⌘V` pastes screenshots and Finder files on this Mac too.** A screenshot taken to the clipboard (`⌘⌃⇧4`) is saved to a file and its path pasted, so you can hand it to Claude Code or Codex without saving it first. A file copied in Finder pastes as its full path rather than just its name. Copied text pastes as before.
