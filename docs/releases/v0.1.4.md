## Fixes

- **The title bar tabs come up right on every Mac.** On some machines the strip lost a race at launch and stayed squeezed against the right edge, every tab hidden in the overflow arrows. It now keeps retrying until it spans the title bar.
- **A failed launch blames the command only when the command is at fault.** Resuming a session whose id no longer exists used to say the agent "failed to start" and point at Settings. If the CLI runs and accepts its arguments, the header now just says the agent exited, and the reason is in the terminal below. The verdict is fixed when the tab dies, so later edits in Settings don't change it.
- Editing arguments while Temple was still detecting agents no longer skips checking them.
