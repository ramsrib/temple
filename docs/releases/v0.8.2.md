## Fixes

- A session on a Mac host now resizes with the window. When Temple opened a session on a host before it had looked up that host's login environment, the agent kept the size the window had when the session opened. This happened on Macs because they have no `setsid` command. Hosts running Linux were not affected.
- Shift+Enter adds a new line in a session on a host, as it does in a local one. It used to send the message. An agent that was already running before the update keeps the old behaviour until it is restarted: quit it (`/exit` in Claude) and open the session again.
- Esc answers at once in a session on a host whose tmux is older than 3.5. tmux used to wait half a second after each Esc before passing it on.
