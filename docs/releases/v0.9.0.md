## What's new

- **The sidebar puts what is open first.** Each project lists its open sessions at full strength with their activity dot, then the sessions you closed in the last week in gray with how long ago each was active ("2h", "3d"). Older ones are behind Show older. The order updates as you open and close sessions, but never while the pointer is over the sidebar.
- **View Options, the new button beside search.** Sort projects by recent activity, name or your own order, and separately sort the sessions in each project by recent activity, name, date started or your own order. Hide Closed Sessions leaves only what is open. Group by Host puts each machine's projects under its name, which folds, and is on by default once you have a project on a host.
- **Drag a session to reorder it.** Press a session in the sidebar and move it: the row lifts, the others slide aside, and it stays where you drop it. Open sessions move among the open ones and closed among the closed. Escape, or letting go off the sidebar, puts it back. The tab strip keeps its own order.
- **⌃⇥ is a short list in the middle of the window**, one line a tab with its project on the right, so it no longer looks like a search box. Project and machine names are shown separately in ⌘P, ⌃⇥, ⌘K and the title bar, so a long machine name no longer cuts off the project's.
- **Hosts have their own manager.** Manage Hosts…, in the Temple menu and in Settings, lists every host with its address, where it was set up, its last connection test and the sessions still running there, each with its action beside it. Settings now lists your hosts, and a click on one opens it in the manager.
- **The home page has two sections**: Start (new sessions, saying which project they start in) and Continue (recent sessions to resume), with Search, History, Shortcuts and Settings as a line of key hints at the bottom.
- **Keyboard Shortcuts is two columns in six groups**, and History's Open Session by ID… sits beside Refresh.

## Upgrading

- The first time this version opens, it adds when each session started to Temple's data. After that, older versions of Temple ask to be updated rather than open the data.
