## Changes

- The sidebar shows each project's open sessions first, in tab order and at full strength, then the sessions you closed in the last week in gray with how long ago each was active ("2h", "3d"); older ones are behind Show more. The order now updates as you open and close tabs, but never while the pointer is over the sidebar.
- View Options, the new button beside search in the sidebar, sorts projects (recent activity, your own order, name) and, separately, the sessions in each project (recent activity, name, date started, or your own order: drag a session onto another), shows only open sessions, and groups projects under a heading for each host that folds.
- ⌃⇥ is now a short list centred in the window, one line a tab with its project on the right, so it no longer looks like a search box. Project names and machine names are shown separately in ⌘P, ⌃⇥, ⌘K and the title bar, so a long machine name no longer cuts off the project's.
- The home page has two sections: Start (new sessions, saying which project they start in, and one row for any other project or machine) and Continue (your recent sessions to resume). Search, History, Shortcuts and Settings are a line of key hints at the bottom.
- Hosts have their own manager: Manage Hosts…, in the Temple menu and in Settings, lists every host with its status, its connection details with an action beside each, and the sessions still running there, in one place.
- History's Open Session by ID… sits beside Refresh in the header.

## Upgrading

- This version adds when each session started to Temple's data the first time it opens. After that, older versions of Temple ask to be updated rather than open the data.
