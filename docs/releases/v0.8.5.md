## Changes

- The sidebar shows each project's open sessions first, in tab order, then the sessions you closed in the last week with how long ago each was active ("2h", "3d"); older ones are behind Show more. The order now updates as you open and close tabs, but never while the pointer is over the sidebar.
- View Options, the new button beside search in the sidebar, sorts projects by recent activity, your own order or name, shows only open sessions or open ones plus the last day, week or month, and groups projects by host.
- ⌃⇥ is now a centred panel of cards like ⌘P, so it no longer looks like a search box. Project names and machine names are shown separately in ⌘P, ⌃⇥, ⌘K and the title bar, so a long machine name no longer cuts off the project's.
- The home page has two sections: Start (new sessions, saying which project they start in, and one row for any other project or machine) and Continue (your recent sessions to resume). Search, History, Shortcuts and Settings are a line of key hints at the bottom.
- Hosts have their own manager: Manage Hosts…, in the Temple menu and in Settings, lists every host with its status and its actions in one place.
- History's Open Session by ID… sits beside Refresh in the header.

## Fixes

- A session copied to another machine opens there. Temple used to treat a session id as one session everywhere, so after copying a Claude Code transcript to another Mac with rsync, Open Session by ID on that Mac said "Temple here already has this session, on this Mac" and only offered to open the original. A session id is unique on one machine: the copy is now its own session on that machine, with its own row, tab, name and colour, and both can be open at once. The copy starts with its transcript's title, not the name you gave the original.
- Each History page is one machine's sessions: This Mac lists only this Mac's, and each host's page only that host's, so Show in History opens the session's own machine's page and shows that session alone. The Archived shortcut stays on the page you are on.
- The `temple` command acts on this Mac's session with an id; `--host NAME` names a session on another machine, and its tables show a HOST column when a session is on another machine.

## Upgrading

- This version updates Temple's data the first time it opens. If another Temple is still running (an older copy, or a second one), the new one says which; quit that one, then open the new one again. After the update, older versions of Temple ask to be updated rather than open the data.
