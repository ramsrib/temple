## What's new

- **Tabs reconnect after a dropped connection.** When a tab's connection to a host fails (your Mac slept, the network changed), Temple tries to reattach to the same running session, checking for about half an hour when the host cannot answer and starting those checks again after a wake or a usable network change. It leaves a clean detach alone, and stops trying on its own if a reconnect shows no sign of life or keeps dropping; Reconnect is there throughout.
- **Temple says when a disconnected session has ended.** When a later check or an automatic reconnect confirms the session is gone, its tab closes and a sidebar notice says so. A notice for one session offers Open session. Automatic reconnection never starts or resumes an agent.
- **Closing a restored tab on a host asks first.** If you haven't opened it since Temple launched and its session may still be running, Detach leaves it running and Stop asks the host to end it. `temple sessions close` refuses such a tab without `--force`, which closes the tab and leaves the session running.
- **A failed Stop is no longer silent.** If Temple cannot read its record of a restored tab's session, it says the session wasn't stopped. A quit that interrupts the Stop records that the session may still be running.
- **Stopping a new Codex session no longer brings it back next launch.** If Temple identifies the session while its Stop is still in progress, it closes the tab instead of saving it to reopen after a relaunch.
- **Launch notices from several hosts take turns.** A second host's notice now waits instead of disappearing. Counts update when a stop is confirmed or a tab attaches, and a notice disappears when nothing remains to count.
- **A launch interrupted before it reached a host can be tried again.** Detaching or quitting during setup no longer leaves the next open trying to attach to a session that never started.
- **Unused local sessions no longer clutter Archived Sessions.** Temple removes an unused new session from the sidebar once it confirms no transcript exists, including after a relaunch, provided it never recorded a transcript and you haven't pinned, named, coloured, kept, archived or opened the session from History. Cleanup removes older entries that meet the same conditions instead of archiving them. Sessions on hosts are not removed this way.
- **A session on a host takes the keyboard once it connects.** No click needed before typing, unless you had already started typing in a field.
- **Restored tabs and commands behave consistently.** An archived session's tab waits for you to open it; `temple sessions open` reconnects a disconnected tab. ⌘T now follows the other new-session controls and refuses a host whose connection test found tmux unusable.
- **Menus and Home say which agent they start.** Home puts your default agent first, and the File menu and shortcuts card name both agents. The ⌘N picker's rows highlight across their full height, and Settings' refresh command says it checks for Claude Code and Codex.

## Upgrading

Tabs on enabled hosts now try to reconnect automatically after a connection failure. A clean detach still waits for you to reconnect.

Eligible empty local session entries are now removed instead of appearing in Archived Sessions. Entries already archived are kept.
