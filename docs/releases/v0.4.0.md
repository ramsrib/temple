## What's new

- **History is a tab, and it covers every session on disk.** ⌘Y (View ▸ Session History) opens a History tab beside Settings that reads both stores when you show it: Temple's sessions and everyone else's, grouped by day. Search narrows in place, and All / In Temple / Not in Temple, agent and project filters compose with it. Select with click, ⌘-click, ⇧-click and the arrows; ⌘R refreshes, ⌘C copies resume commands. Pressed on History, ⌘Y goes back to the tab you came from.
- **Import brings a session into Temple without running it.** A row's Import, its context menu, ⌘I or the selection bar asks first, then adds the sessions to the sidebar. ⌘Z (Edit ▸ Undo Import) takes back any that haven't been used since. Opening a session from History also makes it a Temple session. When ⌘K finds nothing, it offers to search History for the same text.
- **Temple uses a fraction of the resources.** It now watches only its own sessions, through one file-system stream, instead of holding a watch on every session file on disk. Measured against a real store of about 4,100 sessions: CPU under constant writes from about 50% of a core to 3%, open files from 5,000 to 23, memory from several hundred MB to 24 MB, and the sidebar ready in 1.4s instead of 9s.
- **Settings is a page, like History.** Sections for Agents, Claude Code, Codex and Appearance. Each agent shows what Temple will launch: your Command with a verdict on whether it runs, every detected install in PATH order with the reason any was skipped, and Arguments with Reset to default. Fields commit on Return or when you leave them; Esc reverts. Show output opens a CLI's full output in a copyable popover. Warnings on the home page and on a failed tab open Settings at that agent, and ⌘R on Settings checks again.
- **Settings is accessible.** Every field and segmented control has a name for VoiceOver and Full Keyboard Access, and the segmented controls step with the arrow keys.

## Fixes

- Typing in a Command or Arguments field no longer lags. Each keystroke used to re-apply the appearance to every open terminal.
- Typing "nan" in the font size field crashed Settings, and kept crashing it. Font size chevrons now pull a stored size outside 9 to 24 back into range.
- Clicking the segment that is already selected no longer saves a setting you didn't change.
- The default font was "SF Mono", which Ghostty can't find, so every terminal already drew its built-in font. The default now says so; a family you set is untouched.

## Upgrading

- The first launch migrates the database (two columns added). Nothing is deleted. The launch cache is rebuilt once.
- Settings ▸ Sessions ▸ Show ▸ *All on disk* is gone. Sessions Temple hasn't started, opened or imported live in the History tab; Import or open one to bring it into the sidebar.
