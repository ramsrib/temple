## What's new

- **Hidden tabs stop using CPU.** Temple now tells the terminal engine when a tab is out of sight, and carries Ghostty's upstream fix that skips redrawing hidden terminals. In a test with 21 busy background tabs, Temple went from about 40% of a core to about 5%. A tab you come back to shows its current output at once.
- **The usage meters are back on the right of the footer**, beside the gear.

## Fixes

- **Temple no longer settles for an old CLI because a probe failed once.** Right after an install, macOS can refuse the first run of a freshly downloaded binary; Temple took that as broken and launched an older `claude` further down the PATH for every new session. A verdict decided by a failed probe is now checked again after 10, 30 and 60 seconds, and Settings shows the actual launch error.
- The released app now writes the usage log at `~/Library/Application Support/Temple/logs/usage.log`. v0.3.0 only wrote it in development builds.
