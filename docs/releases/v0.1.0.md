The first public release. Temple is a native macOS session manager for Claude Code and Codex: every session you have run, grouped by project, each one a click away from a real terminal that resumes it.

## What's new

- **All your sessions in one sidebar.** Temple reads the agents' own session stores under `~/.claude` and `~/.codex`, groups sessions by project, and keeps the index live: a session started anywhere shows up within a second. Titles come from the CLI's summary when there is one, otherwise your first prompt. Rename and pin sessions from the row's context menu.
- **Real terminals, not transcripts.** Each open session runs in an embedded Ghostty terminal, launched straight into the session's folder. Opening a closed session resumes it; Temple never edits your files, runs git, or touches the session files.
- **Tabs per project.** The tab bar in the title bar shows the active project's open sessions. Switching projects never stops the agents in the others. Tabs reorder by drag and come back after a relaunch as inert chips that start their agent only when you click them.
- **Activity you can trust.** Green means the agent is working, gray means it is waiting for you, orange means a background session needs attention. A bell from a background session also posts a macOS notification that takes you to it. Closing a tab whose agent is still working asks first.
- **Keyboard first.** ⌘K jumps to any session, ⌘T starts a new one in the current project, ⌘W closes a tab, ⌘1 to ⌘9 pick a tab, ⌘B toggles the sidebar, ⌘N goes home, and ⌘/ lists the rest.
- **A home page for starting work.** New Claude or Codex sessions, a session in any folder, and your recent projects, one click each.
- **Settings as a tab.** Font size, theme (System, Light or Dark; the terminal follows), default agent, and a Command and Arguments field for each agent. Temple finds `claude` and `codex` on your login shell's PATH.

## Install

- Download the `.dmg` or `.zip`, drag Temple to Applications, and launch. Releases are signed and notarized.
- Needs macOS 14 or later on Apple Silicon, with Claude Code and/or Codex installed.
