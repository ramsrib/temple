## What's new

- **History's search field keeps its own editing keys.** While you type in History's search, ⌘A now selects the typed text instead of every row, ⇧ with an arrow selects text, and ⌘C and ⌘⌫ act on the text too, so ⌘⌫ in an empty search field no longer archives the selected sessions. Arrows, Return and Esc still drive the list from the field. Click a row, or press Tab, to give the list the keyboard; then ⌘A, ⌘C, ⌘⌫ and ⇧-arrows act on rows.
- **⇧ with an arrow selects text in ⌘K, the ⌘N picker and the sidebar search.** Those fields used to take ⇧↑ and ⇧↓ as a move through the list. The plain arrows still move it.
- **A clearer fold for the projects past the first eight.** "Show all projects (N more)" is now a row set like a project header, **N MORE PROJECTS**, standing where the rest of the projects would be; once they are out, **SHOW FEWER PROJECTS** at the end of the list folds them back. The count no longer includes the active project, which was counted as hidden while it was on screen.
- **Sturdier file watching and quitting.** Temple no longer handles a batch of file changes from inside the watcher that delivered it, and when a watched folder disappears it lists the session stores again, so a change made in that moment is not missed. Quitting with no tabs open now stops Temple's background work before it exits, and every quit waits up to two seconds for it to finish.
- **Old History cache files are cleaned up.** Temple deletes the History cache files left by earlier versions (a few MB each) when no other running Temple is using them.
