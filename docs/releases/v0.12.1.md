## What's new

- **Scrolling back works in an Antigravity session on a host.** Scrolling up with a trackpad or mouse stuck at the bottom of the history, showing only a yellow `[0/N]` in the corner, because a slight sideways scroll or any pointer movement dropped back out of it. History now scrolls as it does in a plain shell, and the first key you type still returns you to the prompt. The same fix applies to any program on a host that doesn't handle the mouse itself.
- **The first key you type returns to the prompt on every host.** On a host where `VISUAL` or `EDITOR` is set to vi, vim or nvim, a key typed while scrolled back moved a cursor through the history instead.

## Upgrading

The fix reaches a host the next time Temple opens a session on it.
