## What's new

- **Tighter tab chips.** Chips sit edge to edge with a hairline between them. The activity dot rides on the agent badge instead of taking its own space, and an exited agent grays its badge. The ✕ takes the title's color and lights only when the pointer is on it.
- **The tab strip remembers where each project was scrolled**, so switching projects and back no longer shifts the row.
- **The + menu asks which agent.** It lists Claude Code and Codex under "New session", each with its own mark, the default agent first with ⌘T beside it where ⌘T applies. An agent that won't launch is disabled and says why.
