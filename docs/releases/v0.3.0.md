## What's new

- **The sidebar shows Temple's own sessions.** By default, the sidebar, search, history and the archive now list only sessions Temple started or opened, plus any you pinned, renamed, colored or archived. Settings ▸ Sessions ▸ Show ▸ *All on disk* brings back everything the CLIs have written. Switching writes nothing.
- **Codex subagents no longer pose as their parents.** Subagent rollouts are left out of the index, and each Codex thread is keyed by its own id.
- **The usage meter reads the Keychain in-process.** Automatic polls never raise a prompt. If Temple needs permission, the usage card says so, and View ▸ Refresh Usage is the one control that asks. An expired sign-in is reported as such, and every read is logged to `~/Library/Application Support/Temple/logs/usage.log`.
- **Shells identify as Temple** (`TERM_PROGRAM=Temple`), and a closed tab's leftover terminal messages (a title, say) no longer land on the next tab.
- **The hidden sidebar stays hidden** when a drag crosses the window's left edge.

## Upgrading

- The first launch migrates the database (two nullable columns added). Nothing is deleted.
- Sessions from before this release show up only if they were pinned, renamed, colored, archived, retitled in a Temple tab, or are open as tabs. Anything else reappears once you open it again, or right away with *All on disk*.

## Known issue

- When a Claude conversation moves to a new id inside a Temple tab (`←`, `/bg`, `/clear`), the new id isn't added to Temple's sessions yet, so it doesn't appear in the default view. *All on disk* shows it.
