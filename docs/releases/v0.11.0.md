## What's new

- **Antigravity sessions on your other machines.** Start an Antigravity (`agy`) session on a host from the `+` menu, `⌘N` or the folder sheet, as you would Claude Code or Codex. Like a new Codex tab, it reads "New Antigravity session" until you send the first prompt; Temple then learns which conversation it is from the `agy` process that tab started, and the tab joins the sidebar under its own title. Reopening it later resumes it on that host.
- **Test connection checks for Antigravity too.** A host without `agy` is not flagged as a problem; Antigravity is greyed out for that host's projects, with the reason.

## Fixes

- When `agy` had crashed, Temple's reader could leave a stray file beside its conversation on this Mac. Temple now reads such a conversation from a private copy, and never creates a file in `agy`'s folder, here or on a host.

## Known issue

- After `/clear` in an Antigravity tab, Temple keeps showing the tab's first conversation, as it does for Claude Code.
