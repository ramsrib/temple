## Fixes

- A session on another machine recovers after your Mac sleeps or the Wi-Fi changes. When the connection came back half-working, reconnecting could fail on the way and leave the tab with an error, no Reconnect and no retry, so only quitting Temple got it back. The tab now keeps its session, says it couldn't reconnect, keeps trying on its own (and again when the Mac wakes or the network returns), and its Reconnect Now button tries at once. The same goes for a new Codex session on a host that Temple hasn't matched to its conversation yet.
- Temple now logs what happens to remote tabs (disconnects, what the host said, each reconnect and retry) in `logs/remote.log` in its data folder, with file paths and anything that looks like a password or token left out, so a dropped session can be traced.
