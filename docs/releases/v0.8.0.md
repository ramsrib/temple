## What's new

- **Continue sessions another Mac's Temple started.** When a host runs Temple too, History has a page for it: the menu before the search field lists This Mac and each enabled host. Choosing a host lists that Temple's sessions, with their names and colours, beside the ones Temple here already has there. Open resumes a session on the host in a tab here, and Import brings it into the sidebar with its name and colour, with Undo. Temple only reads the other Temple's list and never changes it. When a search on This Mac finds little, History offers to look on a host.
- **Open any session by its ID.** File ▸ Open Session by ID…, the same link on History, or a session ID pasted into ⌘K opens any Claude Code or Codex session on this Mac or a connected host, whether Temple started it or not. Temple works out which agent it belongs to and the folder it ran in, and asks only when it can't tell. It says a session wasn't found only after looking through every session on that machine.
