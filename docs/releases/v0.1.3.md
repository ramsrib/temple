## What's new

- **Temple finds the agent that actually runs.** It reads your PATH from a login, interactive shell (so `.zshrc` counts), runs every `claude` and `codex` it finds, and uses the first one that works. A stale install earlier on the PATH no longer gets picked over a current one.
- **Settings says what's wrong.** Each agent lists every install it found, its version, and the CLI's own words for why one was skipped. A banner on the home page names the problem when nothing runs or your override or arguments fail. Your own Command override always wins, even a broken one, and Temple tells you it is broken.
- **A failed launch shows what Temple ran.** A header above a tab that died at startup shows the exact command line.
- **Arguments are split like a shell splits them**, so `--append-system-prompt "be terse"` stays one argument.
- **Thin scrollbars** in ⌘K and Settings, even with "Show scroll bars: Always".

## Fixes

- A CLI that never returns from `--version` can no longer hang Temple at launch.
- Shells that reject `-lic` (csh, tcsh) now still provide a PATH.
- A Codex exec prompt buried deep in a large rollout can still title its session.
