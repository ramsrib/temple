## What's new

- **Sessions with no name read "Untitled Session".** A session that hadn't been given a title showed as "claude: storefront" or "New Claude session", the same words on every such row. They now read "Untitled Session" in the sidebar, tabs, ⌘K, ⌃⇥ and History.
- **Open and closed sessions are easier to tell apart in the sidebar.** Open sessions are a step bolder with their icon in full colour. Closed ones are lighter with a faded icon.
- **History has a simpler header.** One row: search, All and Archived, Filter, and a "…" menu with Refresh and Open Session by ID. In Temple and Not in Temple moved into Filter. The counts are gone, and a row only ends in a word when there is something to do with it (Restore, Import).
- **⌘K shows one line per session**, the same row as ⌃⇥, and the selected row looks the same in ⌘K, the new session list and ⌃⇥. The row under the pointer is fainter, so it no longer looks like a second selection.
- **Settings opens with Appearance**, and a tab whose agent failed to start shows the command it ran only when you ask (Show Command), unless the command is what failed.

## Fixes

- Switching with ⌃⇥, ⌘P and ⌘K is quicker. Temple was asking the disk about every project's folder each time the window redrew.
