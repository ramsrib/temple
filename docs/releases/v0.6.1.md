## What's new

- **Keyboard shortcuts that match Chrome and Cursor.** ⌘⇧[ and ⌘⇧] now step to the previous and next tab, as in every Mac browser and editor, and ⌘9 jumps to the last tab. ⌘⇧P opens the command palette, beside ⌘K. Your everyday keys are unchanged: ⌃⇥, ⌘P, ⌘T, ⌘W, ⌘⇧T and ⌘K work as before.
- **⌥ means the other agent.** ⌥⌘T starts a session with the agent that isn't your default in the current project, and ⌥⌘N opens the project picker for it. The `+` menu shows ⌥⌘T on that agent's row.
- **The agents' ⌥ shortcuts work in Temple's terminal.** The left ⌥ key now acts as Meta, so Claude Code's ⌥P model picker and Codex's ⌥R, ⌥B and ⌥F reach the agent instead of typing a symbol. The right ⌥ still types special characters (π, or # on a UK keyboard).
- **⌃⌘F enters full screen again.** With a terminal open it opened the find bar instead.
- **Menus and the shortcuts card follow.** The Window menu has Show Previous Tab and Show Next Tab, ⌘R reads Check Agents Again on the Settings tab instead of a greyed Refresh History, and the ⌘/ card lists the new keys plus the ones the History tab owns. In the ⌘N picker, a host's row now reads "Choose folder on <host>…", like the row above it.

## Upgrading

Three keys moved:

- The picker for the other agent is ⌥⌘N (was ⌘⇧N).
- Previous and next project are ⌥⌘[ and ⌥⌘] (was ⌘⇧[ and ⌘⇧], which now move between tabs). ⌘P still switches projects.
- In the terminal, the left ⌥ no longer types special characters; use the right ⌥ for them.
