## What's new

- **A project switcher in the title bar.** It names the project your tabs belong to and lists every project with sessions open, with a dot where an agent is working or waiting on you. Choosing one returns you to the session you were last on there. ⌘⇧[ and ⌘⇧] cycle projects.
- **Sessions keep the name they give themselves.** When Claude or Codex retitles a session, the sidebar and ⌘K follow it, and the name survives closing the tab and quitting. A rename still wins.
- **Drop files and images onto an agent.** A dropped file is typed into the terminal as its quoted path. An image dragged from a browser or Preview is saved to a temporary PNG and passed as a path.
- **Shift+Return inserts a newline** in Claude Code and Codex instead of submitting. Ctrl+Return and Shift+Backspace work again too.
- **The keyboard lands where you clicked.** Opening a session, switching tabs or projects focuses the terminal, and ⌘K and ⌘F type into their fields instead of the agent behind them.
- **Show more reveals ten at a time** and says how many remain; Show fewer folds the project back.
- **A new app icon:** a temple gate with a terminal prompt in the doorway.
- **Homebrew:** `brew install --cask ramsrib/tap/temple`.

## Fixes

- Quitting no longer erases the tabs it is meant to restore. ⌘Q used to close every tab on the way out, so the next launch had nothing to bring back.
