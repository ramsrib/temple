## What's new

- **Tabs that sit still.** Session chips have a fixed width, so an agent rewriting its title no longer shifts the row. The active tab reads at full weight with a hairline border; resting tabs step back.
- **The sidebar matches the tabs.** Agent badges rest quieter and come to full strength on open or hovered rows, and the highlighted row gets the same "you are here" treatment as the active chip.
- **A session that resumes on its own shows as working again.** The green dot used to come back only after you pressed Return; answering a permission prompt with one key, a click, or the agent waking itself now counts too.
- **A resume into a missing session is explained.** Claude's `/resume` and `/clear` move a conversation to a new id, so a tab can later resume an id with no transcript. The failure header now says so and points to the sidebar, where the conversation still is.

## Fixes

- The sidebar no longer lags while agents are working. Title updates are batched, and the per-session checks that ran on every update are cached.
