## Fixes

- **Cancel keeps the window open.** The prompt after the red close button now appears before the window goes, so Cancel leaves everything as it was. One click shows one prompt.
- **Temple can always be quit.** With a tab whose agent had already exited, the close button and ⌘Q could both do nothing at all.
- Quitting from the Dock while the window is minimized or hidden now asks when an agent is working, instead of shutting it down silently.
