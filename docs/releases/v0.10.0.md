## What's new

- **Antigravity sessions, for Gemini models.** Temple now runs Google's Antigravity CLI (`agy`) beside Claude Code and Codex. Start one from the `+` menu, the home page or `⌘N`. Its past conversations appear in the sidebar and History under their own icon, titled the way `agy` names them, and open where they left off. Settings has an Antigravity section for its command and arguments.
- **A new Antigravity tab finds its own conversation.** `agy` creates a conversation only when you send the first prompt, so the tab reads "New Antigravity session" until then. Temple then asks that tab's own `agy` process which conversation it holds, so two tabs in the same folder never swap.
- **`⌘T` and `⌥⌘T` start the first two agents**, your default first. The third is in the `+` menu, and each menu row shows the key that starts it.

## Fixes

- A fresh Temple could fail to open its database while Codex's background app server was running. Temple now skips the one kind of open file it could not read.

## Known issue

- Antigravity runs on this Mac only for now: projects on another machine don't offer it.
- After `/clear` in an Antigravity tab, Temple keeps showing the tab's first conversation, as it already does for Claude Code.
